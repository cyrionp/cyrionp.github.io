# cyrionp.github.io

Abdulkadir Durmaz'ın kişisel sayfası — tek sayfa, [Three.js](https://threejs.org) ile canlı bir arka plan.

- `index.html` — içerik
- `assets/css/style.css` — stil (mobil uyumlu, `prefers-reduced-motion` destekli)
- `assets/js/scene.js` — Three.js sahnesi
- `assets/js/ui.js` — başlık / yazı animasyonları

Derleme adımı yok; GitHub Pages doğrudan servis eder. Lokal: `python3 -m http.server`.
